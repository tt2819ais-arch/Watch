# Watch

Минималистичное iOS-приложение для просмотра аниме, фильмов и сериалов.
Серии хранятся не в приложении, а проигрываются через сторонние плееры
(AniLibria, Kodik). Нативный SwiftUI, iOS 16+.

## Возможности

- **Контент**: аниме (AniLibria, бесплатно), фильмы и сериалы (Kodik — нужен
  токен в Настройках). Архитектура расширяемая — можно добавить любой
  источник, реализовав протокол `ContentSource`.
- **Поиск с подсказками** (T9-стиль): по мере ввода приложение подгружает
  список совпадений из всех источников и сортирует по релевантности.
- **Фильтры**: жанры, год выпуска, сортировка (популярность / год / рейтинг
  / название / недавние).
- **Темы**: чёрная, белая, серая. Везде жирная Apple-типографика
  (`SF Rounded` heavy/bold).
- **Главный экран**: блок «Продолжить просмотр» — на какой серии и минуте
  остановился.
- **Плеер**:
  - AVPlayer + HLS (AniLibria), WebView fallback для embed-источников.
  - Picture-in-Picture (продолжает играть при сворачивании).
  - Автопауза экрана отключена во время просмотра.
  - Замочек блокировки (двойное нажатие на иконку — разблокировка).
  - Переключение качества (480/720/1080/2160) и озвучки.
  - Возобновление с той же минуты после выхода из приложения.
  - Авто-переход к следующей серии.
- **Избранное**: добавление/удаление сердечком на странице тайтла.
- **Статистика**: просмотрено серий и минут/часов за сегодня, вчера, неделю,
  месяц, всё время.
- **Логи**: подробный лог всех действий пользователя и сетевых ошибок,
  можно скопировать одним нажатием в Настройках → Логи приложения.
- **Оффлайн-устойчивость**: прогресс, избранное, статистика и логи
  хранятся локально в Documents/.

## Дизайн

- Чисто минимализм. Никакого неона/киберпанка/градиентов.
- Иконка приложения — чёрный квадрат с буквой `W`. Не привязана к жанру.
- Боковое меню слева (gestures + кнопка-бургер).

## Сборка локально (нужен Mac)

```sh
brew install xcodegen
xcodegen generate
open Watch.xcodeproj
```

## Сборка через GitHub Actions

При каждом пуше CI собирает unsigned `Watch-unsigned.ipa` и кладёт его в
артефакты Actions. Скачать: вкладка **Actions → последний run → Artifacts →
`Watch-unsigned-ipa`**.

`.ipa` не подписан, поэтому ставить на устройство нужно через:

- **AltStore / Sideloadly** (бесплатный Apple ID, переподпись каждые 7 дней),
- **TrollStore** (если совместимая версия iOS),
- или подписать своим Apple Developer аккаунтом перед установкой.

## Структура

```
Watch/
├─ App/            — точка входа, AppState, RootView
├─ Theme/          — палитры тем + bold-типографика
├─ Models/         — ContentItem, Episode, WatchProgress, …
├─ Services/       — Logger, Persistence, Stats, Favorites, Progress
│  └─ API/         — HTTPClient, ContentSource протокол + источники
└─ Features/
   ├─ Root/        — боковое меню
   ├─ Home/        — главный экран + Continue Watching
   ├─ Search/      — поиск с автоподсказками
   ├─ Catalog/     — список тайтлов с фильтрами (Anime/Movies/Series)
   ├─ Detail/      — карточка тайтла + список серий
   ├─ Player/      — AVPlayer, PiP, замочек, переключение качества
   ├─ Stats/       — статистика просмотров
   ├─ Favorites/   — избранное
   └─ Settings/    — темы, источники, логи
```

## Источники видео

| Источник   | Аниме | Фильмы | Сериалы | Нужен ключ            |
|------------|-------|--------|---------|------------------------|
| AniLibria  | да    | —      | —       | нет                    |
| Kodik      | да    | да     | да      | да (вписывается в UI)  |

API ключи и любые другие секреты можно добавить в **Настройки → Источники**.
Никогда не коммить токены в репозиторий.
